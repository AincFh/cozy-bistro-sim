# COZY BISTRO · 日落餐馆

一个离线优先、无需账号的网页餐馆经营模拟游戏。原创游戏机制与视觉设计。**当前状态：可玩经营模拟版本，仍在内容扩充中，不宣称商业级完整作品。**

## 玩法
1. 开业前购买食材或升级厨房。
2. 开门迎客，根据客人的菜单和剩余耐心安排制作。
3. 厨房有并发制作台，升级后可同时处理更多订单。
4. 制作完成后亲自上菜；及时服务可获得小费、经验与口碑。
5. 每日结束查看收益、损耗与客人满意度，再进入下一天。
6. 逐步解锁 8 道菜品、5 类升级以及 7 项成就。历史财务账本记录最近 24 天。

## 技术
- HTML/CSS/原生 JavaScript，独立引擎 \`src/engine.js\`，不使用外部 CDN、框架或商业素材。
- 进度写入浏览器 localStorage，页面提供手动导出和导入、重新开始。
- 自适应布局。GitHub Actions 在每次 Push/PR 时执行 Node.js 测试；main 部署 GitHub Pages。
- \`npm test\`：引擎及经济闭环测试。
- \`npm run check\`：JS 语法检查。
- \`npm run start\`：本地启动后打开 http://localhost:5173。

## 边界
目前是单机经营模拟游戏而不是 3D 自由探索或多人联机；数据仅留在使用的浏览器和手动导出的备份中。清理浏览器站点数据会删除存档。没有真实支付、用户账号或服务器运营后台。
## 经济保护与离线支持
低资金或无法制作任何已解锁菜品时，每个营业日最多可领取一次免费邻里应急食材。支持状态随本地存档保存。字体使用系统字体，无外部字体请求。
